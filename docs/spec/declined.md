# やらないと決めたこと

ochakai は**足さない**ことを既定にしている([surface.md](../surface.md) の
三つの問い)。ここは、断るとき・撤去するときの規則と、撤去したものを戻す
条件を持つ。**いま断っていることの一覧の正は [ROADMAP](../../ROADMAP.md) の
「Considered and deliberately not doing」**で、各項目がそれを決めた記録を
指す。一覧をここに写さないのは、二つの写しはどちらが古いか分からなくなる
からである。

## 断り方

- **断るのは、八つの条件のどれにも当たらない提案と、三つの問いに答えられ
  ない提案である。** 条件に当たることは必要条件であって十分条件ではない。
- **断ることには、戻す条件を添える。** 「使われていない」「誰も詰まって
  いない」が理由なら、実際に詰まった一件が出たときが戻す条件になる。
  条件の無い「やらない」は、後から誰も問い直せない。
- **ROADMAP の段階として予定していることを、別の場所で「やらない」と
  書かない。** 決めたことの置き場所は一つにする — 0142 の「グラフを
  持たない」が二日で覆ったのは、その二つがずれていたからである。

## 撤去の基準

撤去するのは、**設計が間違っていたときではなく、費用対効果の前提が
覆ったとき**である。覆ったと言える観測は三つある。

- **利用が無い。** 想定した利用者が現れないまま時間が経った。
- **文書が自分で降格させている。** 使わない前提の説明が書かれているのに、
  コードだけが第一級で持ち続けている。
- **保守の面積と、その面が引き受け続ける債務**(セキュリティレビューの
  対象であり続ける、外部仕様への追従を抱え続ける)。

撤去しても、**利用者のナレッジは消さない** — 型は自由な文字列として書ける
まま残り、履歴の行も残る。撤去は 0.x の BREAKING として告げ、猶予は置かない
([mcp-cli-stability.md](mcp-cli-stability.md))。

## 撤去したものと、戻す条件

| 撤去したもの | 戻す条件 |
|---|---|
| ochakai 自身が OAuth の認可サーバになるコネクタ | 戻さない。代わりに、自分で検証するデプロイが `/mcp` の 401 で発行者を教える形で Claude のコネクタが繋がる([identity.md](identity.md)) |
| 決定的な SQL コンパイル(`compile_sql`)と、セマンティックモデルの専用機構 | 聞かれたことの無い組み合わせを SQL にする要求が、検証済みのクエリの検索で足りないと確かめられ、外部仕様への追従を引き受ける用意があるとき |
| 検索 + 全文 + リンク + 予算を一回で返す pack(`/context`) | 一回の HTTP 呼び出しで読むもの一式を要するホストが実際に詰まったとき([faces.md](faces.md)) |
| 改名の猶予 | 1.0 のとき、または改名で設定が壊れた実際の報告([mcp-cli-stability.md](mcp-cli-stability.md)) |
