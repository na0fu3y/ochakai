# MCP・CLI の安定性契約

MCP のツールと CLI のコマンドは、0.x のあいだ**不安定な面**である。利用者に
向けた方針の正は [compatibility.md](../compatibility.md) にある。

- **名前・引数・出力の形は minor で変わりうる。** 変わるときは CHANGELOG に
  **BREAKING** と書き、使う側が何をすればよいかを書く。
- **改名にも削除にも猶予を置かない。** 改名したリリースから古い綴りは
  答えず、MCP は unknown tool、CLI は unknown command で失敗する。
  `tools/list` と `ochakai help` が、いま呼ぶべき名前を言う。黙って別の
  ことをするのではなく、呼んだその場で失敗するので気づける。
- **CLI はサーバーと一緒に上げる。** 同じ版で出荷されるので、一つ前の CLI は
  動いた形を読んでいるかもしれない。
- **サポートするのは最新のリリースだけ**で、修正は次のリリースで届く。
- 1.0 を切るときに、MCP と CLI の契約を決め直す。凍る面が増えれば、名前の
  猶予はその契約の一部として意味を持ちうる。0.x のあいだでも、改名で設定が
  壊れた実際の報告が出れば、猶予を戻す理由になる。
