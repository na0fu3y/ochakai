# ochakai 決定ログ

**問い直されそうな選択を、短く、書き換えずに残す場所**である。現行の
振る舞いは[現行仕様](../spec/README.md)が持ち、ここは「なぜ他の案に
しなかったか」だけを持つ。

番号は [docs/design](../design/README.md) の 0001–0152 に続き、0153 から
振る。`docs/design` の記録は履歴として残り、書き換えない。

## いつ書くか

振る舞いを変える PR は、まず現行仕様の文書を直す。そのうえで、**三か月後に
誰かが「なぜこうしなかったのか」と問い直しそうなとき**だけ、ここに一本
足す。規則を一つ足す、数を変える、名前を直す — そういう変更は現行仕様と
CHANGELOG で足りる。

## 形

    # NNNN: <題>

    Date: YYYY-MM-DD
    領域: <領域名を、../spec/ のその文書へのリンクにする>

    ## 背景
    ## 決定
    ## 退けた案
    ## 戻す条件

**60 行まで**(CONTRIBUTING.md の `DECISION-LINES`)。超えるなら、二つの
決定か、現行仕様に書くべきことを書いている。一度入った決定ログは
書き換えない。決定が覆ったら、新しい決定ログを足し、現行仕様を直す —
古い方に注記は要らない。
