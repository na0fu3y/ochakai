# ochakai 設計ドキュメント 0115: コネクタの値段は変わり、その条件は変わらない

Status: Accepted(2026-08-22)。[0070](0070-what-was-retired-and-why.md) §5 の
「コネクタ — 戻すときは revert が出発点になる」を改訂する — 出発点が
[0010](0010-mcp-oauth-connector.md) の認可サーバではなくなった。**戻す条件は
一字も動かさない**(§3)。[0086](0086-a-second-way-to-say-who-is-calling.md) の
in-process 検証も [0065](0065-identity-and-provenance.md) §1 の「認可を持たない」
も動かない
Date: 2026-08-22

## 1. 測ったこと

[0012](0012-retire-mcp-oauth-connector.md)(いまは 0070 §2)が公開コネクタを
撤去したのは 2026-07-18 である。**その三週間後に 0086 が着地した** —
発行者を名指したデプロイが Bearer トークンを自分で検証する経路であり、
これは「ochakai が認可サーバである必要はない」という意味を持っていた。
0012 はその世界を知らずに値段を見積もっている。

そこで測った(PR [#721](https://github.com/na0fu3y/ochakai/pull/721))。
デプロイが公開するのは二つだけである:

- `GET /.well-known/oauth-protected-resource[/<resource のパス>]` —
  RFC 9728 のメタデータ。`resource` と `authorization_servers` は
  **`OCHAKAI_OIDC_AUDIENCE` と `OCHAKAI_OIDC_ISSUER` がそのまま入る**。
  文書が言うべき二つの事実は、0086 のデプロイが既に名乗っている二つと
  同じものだった。
- `/mcp` の 401 に `WWW-Authenticate: Bearer resource_metadata="…"` —
  握手の最初の一歩。0010 §4.1 が「claude.ai は 200 上のこのヘッダを
  無視する。401 が必須」と実測を残している。

**結果は成立である。** vendor がホストするクライアントが、この文書だけから
別ホストの認可サーバを見つけ、そこに自分を登録し、この audience に束縛
されたトークンを持って戻り、その書き込みは発行者が請け合った人として
記録された。**client_id を人が打った箇所は一つも無い。** 前提のほうも
製品の側に寄っていた — 別ホストの認可サーバを指す `authorization_servers`
は、いまはクライアント側の文書に載っている構成である。

## 2. 決定: 出発点を差し替える。条件は差し替えない

0070 §5 は「三つとも設計は残っているので、戻すときは revert が出発点に
なる」と書いた。コネクタについて、**それはもう正しくない**。

戻す日の出発点は、`internal/connector` の 863 行(+ テスト 686 行)の
認可サーバではなく、**上の二つの答え**である。実装は
`internal/httpauth/discovery.go` として測定済みで、コミット
[`abbfdfd`](https://github.com/na0fu3y/ochakai/commit/abbfdfd) にある —
テスト込みで 180 行あまり、環境変数はゼロ増、姿勢もゼロ増。

**8 倍の差は、この記録が持って帰る唯一の数である。**

## 3. なぜ、いま採用しないのか

0070 §2 がコネクタ一つで壊れると数えた四つの性質のうち、**二つは本書 §1 の
構成では発生しない** — 唯一の secret(認可サーバを持たないので Google
OAuth クライアントが要らない)と、公開 AS 固有の攻撃面(CIMD の fetch も
authorization code も refresh token も無い)。残る二つ、唯一の公開サービスと
Domain Restricted Sharing の例外は、**公開到達そのものの代金**であって、
実装を安くしても買い戻せない。

そして 0070 §1 が撤去を正当化した四つの観測のうち、**一つ目は動いていない**:

> 利用がない。想定した利用者が具体化しないまま時間が経った。

[docs/surface.md](../surface.md) の一つ目の問い ——「誰が、何をしていて
詰まったか」—— の答えは、今日も「まだ誰もいない」である。**それは
0012 が撤去したときの理由そのものであり、実験はそこに一言も触れていない。**
安くなったのは実装であって、需要ではない。

そして採用が引き受けるものは、コードではない。デプロイガイドが全編で
言っている「書けるデプロイに `allUsers` は決してだめ」を製品として
書き換えること、0066 §7 が declined したレート制限と濫用対策、
SECURITY.md の脅威モデルを二経路にすること(0010 §5 に文案がある)、
そして §4 の三つを手順として書くこと ——`DOC` と `DOC-LINES` が動く。
**180 行の隣に付いてくるのは、180 行ではない。**

## 4. 値段は消えたのではなく、運用者の IdP に移った

実験が見つけた中で、0012 がどこにも数えていなかったものである。
**どれも ochakai のコードではなく、差分からは一行も見えない。**

1. **クライアントが自分で登録できることは、発行者の既定ではない。**
   素の Keycloak はポリシー三枚(`Trusted Hosts`・`Allowed Client
   Scopes`・`Allowed Client Templates`)で三度断った。**「人が事前登録
   しなければならない発行者は、それ自体が答えである」という判定は
   デプロイごとではなく発行者ごとに出る。**
2. **scope を広告しないことは、scope 無しのクライアントを生まない。**
   `scopes_supported` を出さず、チャレンジにも `scope` を置かなくても、
   クライアントは登録時に `scope: openid` を送る。0065 §1 は
   **ochakai についての事実であってワイヤについての事実ではない** —
   そして発行者の既定ポリシーがそこで断ると、**こちら側からは
   「登録できなかった」以上のことが読めない**。
3. **access token に verified email が無ければ、人は process になる。**
   0086 §4 の綴りが、ブラウザを通った人のトークンに当たったときの姿で
   ある。これは §1 の機構が無くても今日すでに起きているので、独立した
   決定として [0116](0116-a-person-recorded-as-a-process-says-so.md) が
   持つ。

**採用する日の記録が読者に負っているのは、二つの答えよりもこの三つである。**
二つの答えは書いたとおりに動いた。

## 5. 面

**一つも動かない。** この記録が決めるのは出発点であって、面ではない。

採用する日に動くものだけ、先に書いておく。**`/.well-known` は
`/api/v1` の外の住所である**([0064](0064-rest-stops-at-api-v1.md) が
「REST は `/api/v1` で止まる」と宣言した、その外側)。そして
**`WWW-Authenticate` は [docs/surface.md](../surface.md) の HEADER 次元が
数えない綴りである** — あの節は `api/openapi.yaml` から数え、このヘッダは
`/mcp` に立つからで、同節が `Cache-Control` について自分で見つけたのと
同じ死角である。数え方を先に決めるのが、その PR の仕事になる。

もう一つ、採用する日の起動時の宿題がある: **公開到達のデプロイで
`OCHAKAI_DELEGATING_CALLERS=*` は、検証済みの誰もが任意の人物を名乗れる
という意味になる**(0065 §3)。いま何もこの組み合わせを断っていない。
[0112](0112-a-start-refuses-a-variable-it-does-not-read.md) が起動時の
拒否の形を持っている。

## 6. 採らなかった案

- **いま採用する。** §3。既定の答えは no であり、実験は値段を変えたが
  需要を作っていない。「安くなったから入れる」は、
  [docs/surface.md](../surface.md) が断ると決めている形そのものである。
- **記録を書かず、issue に置く。** 0048 §2.1 の「利用者が観測できる決定」
  には**やらないと決めること**が含まれ、0070 がその現行ドキュメントで
  ある。次に誰かがこの経路を尋ねたとき、答えが「850 行の認可サーバ」
  だったのか「180 行の握手」だったのかは、その人の判断を変える。
- **0070 §5 の条件そのものを緩める**(「実装が安いこと」を再実装の条件に
  加える)。値段は条件ではない。0070 §1 の基準は費用対効果の**前提**で
  あって費用ではなく、分母だけを動かしても分子は 0 のままである。
- **測定用の実装を、無害だからと merge しておく。** 設定しなければ何も
  起きないのは本当だが、面に載った機構は載っている。
  [0068](0068-how-a-face-is-added-and-removed.md) §3 が降ろす側で言って
  いることの、足す側での姿である。

## 7. 再開の条件

0070 §5 の条件を、そのまま引き継ぐ。

- claude.ai / ChatGPT の Web コネクタから組織ナレッジを引きたい利用者、
  または proxy なし直結が必須の MCP クライアント要件が具体化したとき。

そのときも 0065 §1 の原則(到達 = 読み書き、認可なし、OAuth は到達制御と
provenance のみ)は維持する。**変わったのは、その日に開くのが 0010 では
なく `abbfdfd` だということだけである。**
