# ochakai 設計ドキュメント 0087: サンドボックスは、自分がそれだと言う

Status: Accepted(2026-08-09)。[0066](0066-four-postures-one-word.md) の
四つの姿勢に五つ目を足す — 匿名で、書けて、消える。
[0042](0042-public-read-only.md) の公開デプロイの規則(identity を読まない)
はそのまま適用され、read-only の含意だけが外れる
Date: 2026-08-09

## 1. 何が起きたか

この製品の中心は**ループ**である — エージェントが draft を書き、人が
裁定し、使った結果が戻る([0069](0069-the-loop-and-what-measures-it.md))。
README がいちばん長く書いているのもそこである。

そして**それは試せなかった。** 公開デモは `public`、つまり read-only で
あり(0042)、書き戻しを一度でも見るには Postgres を立てて import する
必要があった。**看板の機能が、体験できない唯一の機能だった。**

## 2. 決定: 四つ目のセルを、意図して配る

姿勢は二つの軸(呼び出し元を識別するか / 誰かが書けるか)の四つのセルで、
0066 はその四つ目 — 匿名かつ書ける — を `dev` と名付け、「デプロイでは
絶対に使わない」と書いた。`sandbox` は**同じセルを、意図して配るための
綴り**である。

```
OCHAKAI_MODE=sandbox
```

- **匿名** — `Authorization` を読まず、委譲も読まず、全員 `human:anonymous`。
  理由は 0042 §2.2 と同じで、手前に Cloud Run IAM が無い以上、署名を誰も
  検証していないトークンを信じれば任意の呼び出し元が任意の人物を名乗れる。
- **書ける** — draft も、検証も、結果報告も通る。ループが動く。
- **消える** — ベースは運用者が定期的に復元する。ochakai はそれを行わない
  (それは cron の仕事である)が、**そう言う**。
- **問いを記録しない** — miss は残さない(0051 §3.4)。識別しない相手が
  打ち込んだ文字列は集めない。

### なぜ `dev` の再利用ではないのか

三つある。**`dev` は自分の文書で「デプロイに使うな」と言っている**ので、
公開して使えば製品の記述と矛盾する。**設定を読む人が、事故と意図を
区別できない** — `dev` が公開されているのを見た運用者は、それが誰かの
ミスなのか設計なのか分からない。そして Terraform が `allUsers` を許すのは
公開姿勢だけであり([0042](0042-public-read-only.md))、意図した公開には
意図した綴りが要る。

## 3. 言わないサンドボックスは、書いたものを盗む

**この記録の要点はここである。** 匿名で書けて消えるデプロイに、それと
知らずに本物のナレッジを書き込んだ人は、次の復元でそれを失う。README を
読んでいることを当てにするのは、失われる側にとって何の保証でもない。

だから**製品がそう言う**。`GET /api/v1/stats` が `sandbox: true` を返し、
同梱の Web UI はそれを読んで全ページに一つのバナーを出す — 隠すものは
無い(書けるので)が、言うことがある。

## 4. なぜヘッダではなく `stats` か

read-only は `Ochakai-Read-Only` ヘッダで自分を announce している
([0040](0040-read-only-mode.md))。同じ形にできなかったのは凍結である:
REST は `/api/v1` で凍っており([0064](0064-rest-stops-at-api-v1.md))、
[0082](0082-what-the-freeze-holds-still.md) が凍結の外に置いたのは
**応答専用スキーマへのプロパティ追加**であって、新しいヘッダ名ではない。
ヘッダは「住所」の側であり、そこを動かせるのはセキュリティ上の欠陥だけ
である。

`stats` は既に**ループについて答える面**であり(0069 §5)、そこに載る
のは筋が通っている: 「この数はどれも一時間後に消える」は、その数と
一緒に読むべき事実である。

## 5. 採らなかった案

- **デモを書けるようにするだけ(姿勢は増やさない)。** `public` の
  read-only 含意は 0042 §2.1 が「危険な組み合わせを綴れなくする」ために
  置いたもので、そこを外すと公開デプロイが黙って書けるようになる。
  外すべきなのは含意ではなく、**別の姿勢**である。
- **サンドボックスの復元を ochakai が行う。** 定期的に import する
  コンテナは cron であって製品ではない。運用ガイドに手順を書く。
- **書き込みに TTL を持たせる**(一定時間後に消える concept)。保存形に
  新しい意味を足すことになり、OKF にその概念は無い(C3)。復元のほうが
  単純で、`ochakai import` という既にあるものだけで済む。
- **匿名の書き込みを provenance 付きで記録する**(セッション id など)。
  それは identity であり、0042 §2.2 が公開デプロイについて断ったものを
  形を変えて持ち込む。
- **バナーを出さない。** §3。

## 6. 面

- **ENV** — `OCHAKAI_MODE` に語が一つ増えるだけで、変数は増えない(11 → 13
  は 0086 のぶんで、ここでは動かない)。
- **REST** — `stats` に応答フィールドが一つ。0082 の下の追加であり、
  凍結の指紋は同じ PR で再生成した。
- **Web UI** — 全ページのバナー。人の curation の面なので、ここに出す。
- **MCP / CLI** — 出さない。エージェントが `stats` を読めば分かるし、
  ツール説明文はエージェントのコンテキストから支払われる(0067 §1)。
